# Gento Nurse Management Client

**Gento Nurse Management Client** is a React-based frontend application designed to manage nurse records efficiently.  
It provides a user-friendly interface to **add, edit, delete, and search nurses**, along with options to **export data** in CSV and Excel formats.  

The app integrates seamlessly with the **Gento Nurse Management API** (backend) and uses **Material UI** for modern, responsive design.

---

##  Key Features

- Add new nurse details (Name, License Number, Date of Birth)  
- Edit existing nurse information  
- Delete nurse records with confirmation  
- Search nurses by **name**, **license number**, or **date of birth**  
- Export nurse data as **CSV** or **Excel**  
- Snackbar notifications for all key actions  
- Built with **React + Material UI (MUI)** for a clean, modern interface  

---

##  Tech Stack

- **React.js**  
- **Material UI (MUI)**  
- **XLSX (SheetJS)** – for CSV/Excel export  
- **Fetch API** – for backend communication
